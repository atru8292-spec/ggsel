# price-watcher

Раз в сутки проверяет цену товара на ggsel.net и шлёт в Telegram, если цена ≤ 10000 ₽.

## Деплой

1. Залей папку в GitHub-репо, подключи репо к Vercel как обычно.
2. В настройках проекта на Vercel → Settings → Environment Variables добавь:
   - `TELEGRAM_BOT_TOKEN` — токен бота от BotFather
   - `TELEGRAM_CHAT_ID` — твой chat_id
   **Не клади токен в код и не коммить в репо.**
3. Задеплой. Vercel сам подхватит `vercel.json` и включит cron на `/api/check-price` (каждый день в 09:00 UTC / 12:00 МСК).

## Проверить руками

После деплоя можно дернуть эндпоинт напрямую в браузере:
`https://<твой-домен>.vercel.app/api/check-price`

Вернёт JSON вида `{"ok": true, "price": 12000}`. Если `ok: false` — смотри `reason`/`error`, там будет понятно, что не так (сайт заблокировал запрос или не нашли цену в HTML).

## Важно

- Я не смогла зафетчить страницу ggsel.net вживую (сайт отдаёт 401 на запросы не из браузера) — поэтому `extractPrice()` в `api/check-price.js` работает по нескольким regex-паттернам "на удачу". После первого реального запуска проверь ответ эндпоинта: если `price: null` — открой страницу в браузере, посмотри в исходном коде (Ctrl+U или DevTools), как там реально записана цена, и поправь regex под конкретную вёрстку. Могу помочь, если пришлёшь кусок HTML вокруг цены.
- На Vercel Hobby-плане cron может быть только раз в сутки — этого мы и заложили. Если захочешь чаще — либо Vercel Pro, либо внешний триггер типа cron-job.org, дергающий тот же `/api/check-price`.
- Уведомление шлётся при каждом запуске, если цена ≤ порога (то есть максимум раз в день, пока цена не поднимется — это не спам).
